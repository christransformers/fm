# Adding real music to Fuse

The current community directory is fictional preview content from the uploaded release archive, with static SVG cover artwork. Do not attach real musicians' songs to those fictional identities. Create each real artist's profile using their approved name, photo, bio and tracks.

## First catalogue

1. Invite independent artists to approve a profile and send their SoundCloud track or playlist link with embedding enabled. Use the official player; do not extract its audio. This is the fastest way to show real artists without storing their recordings in this repo.
2. For Fuse's own audio player, obtain written permission covering the recording and the composition, including any collaborators, publishers and samples. Confirm whether collecting-society licensing is needed for the planned service and territories.
3. For openly licensed tracks, verify the licence on the original upload. CC BY 4.0 permits commercial reuse with attribution and other conditions. Record the title, creator, original URL, licence URL and any changes. A search-result label alone is not evidence that the uploader controls every right.

## Track intake record

Keep: artist ID, title, writers, recording owner, source URL, permission/licence evidence, territory, term, artwork credit, explicit-content flag, release date, duration and audio file or official embed URL. Keep private agreements outside this public repository.

## Before public accounts open

The website can stay on GitHub Pages. Real sign-up still needs a hosted authentication service and shared storage. Public comments additionally need moderation, abuse limits, reporting and deletion tools. Artist ID checks must use a secure private process, never this public repo or a browser-only form. Performance videos help assess an application; they are not conclusive proof that a recording contains no AI.
